# 语音指令能力设计与实现记录

本文档记录 AI Voice Draw 计划支持的语音指令能力、当前最终实现情况，以及尚未完成能力的原因说明。目标是让评审者可以快速判断：系统想支持什么、已经做到什么程度、哪些能力仍是后续计划。

## 目标原则

- 用户尽量不依赖鼠标、键盘和工具栏，通过自然语言语音完成绘图创作。
- 简单高频控制优先本地低延迟执行，避免每次都等待模型。
- 复杂绘图指令由 Agent 拆解为可编辑的 Fabric.js / SVG 矢量操作。
- 模型处理期间不丢弃用户后续语音指令。
- 每次操作结果和错误都应提供可理解的语音反馈。
- 绘图结果应保持可编辑对象结构，而不是只生成一张不可修改的扁平图片。

## 状态说明

| 状态 | 含义 |
| --- | --- |
| 已实现 | 当前代码已有对应前端交互、后端工具或本地命令路径。 |
| 部分实现 | 主流程可用，但存在范围、精度、浏览器或后端协议限制。 |
| 未实现 | 当前版本没有完整功能，仅保留为后续计划。 |
| 受环境限制 | 功能受浏览器安全策略、模型能力或外部服务限制，应用无法完全绕过。 |

| --- | --- | --- | --- | --- |
| 语音输入与标准化 | 持续监听语音，过滤口头填充词、噪声和常见识别错误，把自然语言转成绘图指令。 | 部分实现。前端有语音文本标准化、本地命令识别、噪声过滤和常见误识别修正。 | “嗯，画一个圆”“带你来画一辆车” | 浏览器 SpeechRecognition 的识别质量、置信度字段和中文分段行为不稳定，仍需更多真实语音样本优化。 |

| 排版与层级 | 对齐、均匀分布、置顶/置底、前移/后移、成组和取消成组。 | 已实现。后端工具包括 `arrange_object`、`align_object`、`distribute_objects`、`group_objects`、`ungroup_objects`。 | “把三个图形横向均匀分布”“把房子置顶”“把所有图形成组” | 完整图层面板和可视化层级管理尚未实现。 |
| 对象样式编辑 | 改色、纯色填充、渐变填充、描边、透明度、样式复制。 | 已实现。后端工具包括 `change_color`、`change_fill`、`apply_gradient_fill`、`change_stroke`、`change_opacity`、`copy_object_style`。 | “把圆改成绿色”“加蓝到紫的渐变”“用吸管复制这个颜色” | 更专业的色阶、曲线、局部调色和复杂材质填充仍是计划能力。 |

## 最终已实现能力概括

当前版本已经覆盖语音绘图应用的主链路：浏览器语音识别、命令标准化、低延迟本地控制、后端 Agent 拆解、工具执行、Fabric.js 画布应用、语音反馈、基础图形绘制、常见对象编辑、选择、排版、素材导入、同心圆专用处理、透视车辆专用处理和能力公告。

从用户体验上，当前已经可以完成：

- 用语音创建可编辑图形和文本。
- 用语音修改、选择、组织和排版已有对象。
- 用语音执行撤销、重做、清空、停止、重试和导出。
- 对“同心圆内外颜色”“车辆正常 3D 结构”这类简单但容易误解的指令做专用处理。
- 在模型执行期间保留后续语音指令，降低用户输入丢失风险。

## 未完成部分的总体原因

未完成能力主要集中在三类：

1. 浏览器限制：首次麦克风授权必须由用户手动确认，SpeechRecognition 的置信度和中文分段也不稳定。
2. 架构边界：当前主线是可编辑矢量对象，不是像素画笔引擎、专业 3D 建模器或写实文生图系统。
3. 后端协议演进：停止当前绘图已经能保护前端不应用过期结果，但服务端完整取消仍需要异步 run 协议和按 run id 取消的接口。

后续优先级建议：

1. 完善后端任务取消协议，减少长任务资源浪费。
2. 扩展更多结构化 3D / 透视对象工具，而不是只覆盖车辆。
3. 增加像素级画笔和橡皮等基础光栅绘画能力。
4. 引入真实文生图 / 局部重绘 provider，并配套安全校验和素材管理。
5. 继续收集真实语音样本，增强中文口语识别容错。

## 验证方式

- Python 测试：`python -m pytest -q`
- 前端测试：`cd frontend-app && npm test`
- 前端构建：`cd frontend-app && npm run build`
- 语法检查：`python -m compileall agent server tests -q`
- 手工验收重点：
  - “画同心圆，最里面绿色，外层蓝色”应生成内外层同心结构。
  - “画一辆有正常 3D 结构的汽车”应生成包含多个透视结构面的车辆，而不是扁平图标。
  - “撤销 / 重做 / 停止当前绘图 / 导出 PNG”应低延迟响应。
  - 模型执行期间连续说多条指令时，后续指令不应被直接丢弃。
