## 连续轮廓的工具参数

真实的 `cafe-current-stage-checks-full-20261021` 首批调用中，店招的两个面、遮阳篷的两个面、门框和两扇窗框均传入四个不同角点，`closed` 为默认 `false`，也没有重复起点。这些调用实际绘制三条连续边。对应评审持续指出门窗、店招和遮阳篷的连接不完整。

参考上下文为可用的共面窗框提供完整 `path` 记录，明确包含 `points`、`smooth=false` 和 `closed=true`。Agent 可将相关记录放入同一次 `draw_paths` 的 `paths` 数组，继续按原始美术要求选择样式。遮挡处的可见轮廓中断使用独立开放路径；已合格的当前轮廓持续保留。

## 共面四边形

满足以下条件时，提供一个共面开口或面板的构造参考：

- 原始构图为两点透视，两个消失点与声明的视平线一致。
- 同一建筑主体存在唯一的一组竖向顶点与接触锚点。
- 当前职责范围内的形体位于该竖向结构的一侧，并处在同一主体的一个未旋转 `box/plane` 范围内。
- 有明确的父形体时使用该父形体；通过包含关系找到父形体时，选择唯一的最小包含范围。

近端竖边与远端竖边的上下角点向同一个原始消失点收敛，四个角点位于原始形体范围及参考立面内。参考使用形体较短尺寸的 1% 留出窗框与墙面的间距；Agent 继续按实际线宽和图片检查可见间隔。对跨越建筑转角的形体、旋转形体、存在多个竖向结构的情况，以及其他投影类型，使用原始构图和相应的作画方法。

这些四边形适用于安装在对应立面中的开口或面板。突出的体块需要依据原始锚点建立自身的其他可见面。`no_coplanar_interval` 记录该共面假设与参考间距下的空区间；它不修改原始规划，也不会自动拒绝任务。Agent 应核对形体含义，必要时提供具体的约束冲突。

## 接触与遮挡

`planned_connections` 把原始关系编号、两个锚点、所属形体和画布坐标放在一起。山水中的桥与河岸、树根与坡石，以及其他绘图中的支撑和连接，都可以直接使用相应位置。锚点用于定位实际接触面和可见轮廓。

`potential_axis_crossings` 标记建筑构造轴经过其他形体范围的区段。Agent 结合当前图片检查前景轮廓、实体遮挡和轮廓终点。这些区段属于规划中的潜在相交，不能当作当前图片存在缺陷的判定。

构造参考只在 `block_in/contour` 阶段加入上下文。`detail/modeling/edit/research` 继续使用原有输入方式。完整原始 DrawSpec、当前原生对象、图片和工具错误持续保留；参考函数不会写入 SQLite 或画布。

## 擦除没有产生修改时的当前几何

子 Agent 最近一次成功绘图调用是 `erase_strokes`、实际返回 `action_count=0`，并且草稿与调用时的状态一致时，执行记忆增加 `erase_targeting`。该信息通过现有原生几何函数计算，包含：

- 本次选择的当前对象，以及它们到实际笔刷轨迹的距离和最近画布位置。
- 距离该轨迹最近的当前可擦除对象；距离相同时全部列出，保持当前图层顺序。
- 实际笔刷范围内的路径区段。每段简化后的中心线误差不超过一个画布单位；需要更多点才能表达的路径提供检索提示。
- 当前名称、类型、线宽、透明度、填充和锁定状态，以及该擦除模式是否支持对象。

图片坐标使用本输入原始观察的元数据，交给现有坐标转换函数处理。已经完成修改后，该字段不再出现。工具错误继续完整送入上下文，不作为没有产生修改的成功调用处理。原始参数和工具结果保存在原有 SQLite 记录中，可通过 `memory_ref` 读取。

Agent 结合当前图片确定需要修改的实际内容，保持本次输入的范围。选择对象的最近点可能位于指定区域以外；几何距离不判定图片中的可见缺陷，也不自动选择对象、扩大橡皮范围或修改画布。

真实咖啡馆草稿中，同名铺装路径经裁剪生成了新片段。旧编号 `d165c646b8b74281` 的当前路径距笔刷约 94.77 个画布单位；笔刷实际经过的是 `51d1e78f06de5dc6`。同一区域还有合法的门框及门缝，观察会同时列出这些对象，供 Agent 依据图片、名称和图层区分。实际记录见[原生几何回查](assets/child-no-effect-targeting-facts-20261021.json)。

## 检查与真实实验

测试使用已保存的真实咖啡馆及山水 DrawSpec，检查消失点共线、形体范围、立面范围、职责范围、明确父形体、歧义处理、接触锚点及输入保留。真实原生动作检查用计算出的路径创建两扇窗框，核查闭合中心线与角点，实际渲染 PNG，同时确认共享画布尚未被修改。

`python -m pytest -q` 的本次完整结果为 310 项通过，耗时 82.68 秒。新增检查覆盖真实没有产生修改的擦除、重新命中、移动和旋转后的几何、图片坐标映射、重合对象、不同任务隔离及原始工具错误。测试在局部修复通过后的整幅续画期间执行；该续画的完整耗时不用于从空白画布作画的速度比较。

原始参数与计算结果保存在[构造参考事实](assets/child-construction-reference-facts-20261021.json)。该文件说明参数及计算，不作为美术评分。

实际作画继续使用冻结的模型、原始任务、独立评审和完整阶段结束核查。成功、失败、首次共享更新、完整用时、工具错误和人工画质判断分别记录。

使用构造参考从空白画布作画的第一次真实实验，首批创建 19 个原生对象，约 79 秒完成 `block_in` 的独立评审及首次共享更新。后续入口清理出现使用旧片段编号的重复擦除，完整运行由操作者终止，记录了 122 次真实模型请求，其中一次在终止时尚未完成。该实验没有完成整幅作画，首阶段数据不能作为完整耗时改善的证据。

为验证几何回查，从原实验运行期间保存的 SQLite 只读检查点继续同一子 Agent、输入与未完成执行。检查点保存时原运行仍在执行。针对该次入口修复，原运行在检查点后发生三次擦除：一次产生修改，两次没有修改，局部评审仍要求修复。加入当前几何观察后的真实续画发生两次擦除，两次均产生修改；第二次使用第一次裁剪实际返回的新片段编号，局部独立评审通过。其余 32 个原有对象的所有字段保持一致。具体参数和结果见[真实片段重新定位记录](assets/child-native-fragment-retargeting-20261021.json)。

这项续画证明该次局部重新定位有效。整幅作品的完成、从空白画布开始的完整耗时，以及不同题材的美术质量需要各自的真实实验。
