# 子 Agent 的原生擦除定位

相对基线 `748ca49f2121af859bbc697fdb6b2822e5b6a0d5`，运行时只修改 `child_drawing_memory.py` 中的子 Agent 执行记忆，并增加只读模块 `child_geometry_context.py`。主 Agent、完成判定、美术指导、独立评审、DrawSpec、工具定义、原生绘图及几何执行、前端、存储、网络和模型配置保持原样。

## 没有产生修改时的当前几何

子 Agent 最近一次成功绘图调用是 `erase_strokes`、实际返回 `action_count=0`，并且草稿与调用时的状态一致时，执行记忆增加 `erase_targeting`。该信息通过现有原生几何函数计算，包含：

- 本次选择的当前对象，以及它们到实际笔刷轨迹的距离和最近画布位置。
- 距离该轨迹最近的当前可擦除对象；距离相同时全部列出，保持当前图层顺序。
- 实际笔刷范围内的路径区段。每段简化后的中心线误差不超过一个画布单位；需要更多点才能表达的路径提供检索提示。
- 当前名称、类型、线宽、透明度、填充和锁定状态，以及该擦除模式是否支持对象。

图片坐标使用本输入原始观察的元数据，交给现有坐标转换函数处理。已经完成修改后，该字段不再出现。工具错误继续完整送入上下文，不作为没有产生修改的成功调用处理。原始参数和工具结果保存在原有 SQLite 记录中，可通过 `memory_ref` 读取。

Agent 结合当前图片确定需要修改的实际内容，保持本次输入的范围。选择对象的最近点可能位于指定区域以外；几何距离不判定图片中的可见缺陷，也不自动选择对象、扩大橡皮范围或修改画布。

## 真实片段与连续修复

咖啡馆草稿中，同名铺装路径经裁剪生成了新片段。旧编号 `d165c646b8b74281` 的当前路径距笔刷约 94.77 个画布单位；笔刷实际经过的是 `51d1e78f06de5dc6`。同一区域还有合法的门框及门缝，观察会同时列出这些对象，供 Agent 依据图片、名称和图层区分。实际记录见[原生几何回查](assets/child-no-effect-targeting-facts-20261021.json)。

从原实验运行期间保存的 SQLite 只读检查点继续同一子 Agent、输入与未完成执行。检查点保存时原运行仍在执行。针对该次入口修复，原运行在检查点后发生三次擦除：一次产生修改，两次没有修改，局部评审仍要求修复。增加当前几何观察后的真实续画发生两次擦除，两次均产生修改；第二次使用第一次裁剪实际返回的新片段编号，局部独立评审通过。其余 32 个原有对象的所有字段保持一致。具体参数和结果见[真实片段重新定位记录](assets/child-native-fragment-retargeting-20261021.json)。

这项续画证明该次局部重新定位有效。整幅作品的完成、从空白画布开始的完整耗时，以及不同题材的美术质量需要各自的真实实验。

最终保留实现另做了独立复验：只恢复这个原有局部输入，父任务保持 `running`，主 Agent loop 没有启动。实际模型共请求七次，61.32 秒后该子 Agent 自然完成，一次原生擦除清除了剩余片段，没有新的工具错误或没有产生修改的擦除，局部独立评审通过。其余 32 个原有对象的所有字段保持一致，共享画布未修改。全部六次子 Agent 请求保留原始 DrawSpec，工具协议核查通过。详见[最终实现的真实复验](assets/child-retained-targeting-validation-20261021.json)、[实际 PNG](assets/cafe-native-eraser-repair-20261021.png)及[可编辑原生文件](assets/cafe-native-eraser-repair-20261021.excalidraw)。该记录只证明这一局部输入的完成。

## 检查

`tests/test_child_geometry_context.py` 使用真实原生工具和 SQLite，覆盖没有产生修改的擦除、重新命中、移动和旋转后的几何、图片坐标映射、重合对象、不同任务隔离及原始工具错误。检查同时确认只读上下文不写入画布和数据库。运行 `python -m pytest -q tests/test_child_geometry_context.py tests/test_child_drawing_memory.py`。

最终完整检查为 305 项通过，85.34 秒：原有 301 项检查保持原样，新增四项原生定位检查。工具错误与完整 SQLite 参数记录继续保留，没有增加产品的作画动作、轮次或时间限制。

数值构造参考候选曾提供额外的窗框、连接与轴线参考。其完整咖啡馆实验没有证明整幅质量或耗时改善，相关运行代码和专用测试已删除。失败与局部成功分别保存，当前默认上下文只保留通过实际局部验收的原生擦除定位。实验选择及实际调用数据见[上下文候选验收记录](assets/child-context-candidate-decision-20261021.json)。

从空白画布由主 Agent 自行建立山水构图的另一次实验，在子 Agent 创建前终止：四次 `spawn_agent` 参数校验失败，实际子 Agent 执行数量为零，画布仍为空。两次上游回复以 `finish_reason=length`、`completion_tokens=4096` 结束；当时应用和环境参数均未主动设置输出 token 上限。四条工具错误完整送入下一次主 Agent 请求。该记录属于主 Agent 的初始派发路径，不能作为子 Agent 绘画耗时或画质样本，也不能据此推断厂商模型的最高输出能力。具体记录见[初始派发边界](assets/child-initial-dispatch-boundary-20261021.json)。主 Agent、模型配置及网络继续冻结。
