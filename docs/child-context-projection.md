## 原始作画内容

完整 DrawSpec 持续保留在当前任务前缀中。美术指导仍包含当前阶段的绘画顺序，以及视觉重点、内容表达、形式统一、细节取舍和艺术语言的判断。原始标准、构图边界和后续阶段保持完整。

block-in 指导要求每段连续轮廓成为独立路径，彼此断开的线段使用不同的 `paths` 项。临时辅助线与主体轮廓使用独立原生对象；共享边优先复用。这样后续阶段可以按实际编号清理辅助线，同时保留门窗、形体轮廓和相邻部件。

指导中的方向、当前阶段标准和成功标准与原始 DrawSpec 重复时，`art_execution.original_fields` 使用当前前缀中的键名及数组位置引用原值。只有完全相同、且引用更短的字段才使用此方式。Agent 无需额外调用检索工具；相关原值已经在同一次模型输入中。

## 当前对象与路径

当前对象索引保留对象顺序、编号、名称、范围、样式和路径。反复出现的类型、角度、版本、文字和样式编号可以放入 `object_defaults`；对象上明确给出的字段优先。路径中重复的坐标空间和最大中心线误差可以放入 `polyline_defaults`。没有取整或减少路径点，完整属性能够逐字段还原。

仅在序列化后更短时使用压缩索引。原生对象、工具回执及 SQLite 中的记录继续使用原有内容。错误、图片、当前绘画记忆和已有比较记录原样传递。此处只改变模型输入中重复信息的表示。

Agent 可以直接观察已有整幅图片；具体部位仍可请求新的特写。构造修复后的整幅查看继续支持原有独立复核。已有当前 ready 评审时，指导要求返回有依据的绘画报告。报告依据当前图片、实际对象绑定和原始标准，检查职责范围内各个阶段，包括旧对象被替换后的早期阶段。阶段顺序不能作为达标证据，职责之外的形体不能计作自己完成；未完成事项持续保留。
